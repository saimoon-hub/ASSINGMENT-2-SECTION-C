
# Stack and Circular Queue Programs in C

## Description
This repository contains three C programming questions based on Stack and Circular Queue concepts. These programs demonstrate expression conversion, postfix evaluation, and circular queue implementation.

## Programs Included

### 1. Infix to Postfix Conversion
- Convert the infix expression `A + B * (C - D)` into postfix notation.
- Use a stack to perform the conversion.
- Display the stack operations step by step.
- Write the algorithm for infix to postfix conversion.

### 2. Postfix Evaluation
- Evaluate the postfix expression `5 3 2 * + 4 -`.
- Use a stack to perform the evaluation.
- Display the stack contents after each operation.
- Calculate the final result.

### 3. Circular Queue Implementation
- Write a complete C program to implement a circular queue using an array.
- Explain the front and rear modulo logic.
- Implement enqueue and dequeue operations.
- Display the elements of the circular queue.
- Explain the full and empty conditions.
